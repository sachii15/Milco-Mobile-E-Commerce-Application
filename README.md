# MILCO Project

## Overview

This project was developed as an academic project focused on analyzing and designing a solution for MILCO. The project involved understanding the existing business processes, identifying requirements, modelling the proposed system, and documenting the overall solution.

## Project Objectives

* Analyze the existing business processes and requirements.
* Identify problems and improvement opportunities.
* Define functional and non-functional requirements.
* Design an improved system solution.
* Model system processes and interactions.
* Document the proposed solution.
